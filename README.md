<h2>📦 Included Files</h2>

<h3>1️⃣ Accelerometer Mode (Dabble Controller)</h3>
<p>
Control the robot using your phone's built-in accelerometer (tilt sensor) through the Dabble mobile application.
</p>
<ul>
  <li>📱 Phone Tilt Control</li>
  <li>🔵 Bluetooth Communication</li>
  <li>✅ Tested with Arduino IDE 1.8.19 (Windows)</li>
</ul>

<hr>

<h3>2️⃣ Custom App Control (PTH Controller APK)</h3>
<p>
Control the robot using the custom-designed <b>PTH Controller</b> Android application.
The communication protocol is compatible with PictoBlox projects.
</p>
<ul>
  <li>🎮 Custom Button Controller</li>
  <li>📲 PTH Controller APK Support</li>
  <li>✅ Tested with PictoBlox</li>
  <li>⚠️ Not compatible with Arduino IDE 1.8.19 implementation</li>
</ul>

<hr>

<h3>3️⃣ PTH Controller APK</h3>
<p>
Ready-to-install Android application for controlling the robot without writing additional code.
</p>
<ul>
  <li>📱 Android APK File</li>
  <li>🎮 User-Friendly Control Interface</li>
  <li>🔵 Bluetooth Connectivity</li>
</ul>
